# Renoxium brand

The Renoxium mark is the letter **R** whose counter is a speech bubble: a conversation that becomes a business.
The wordmark is **renoxium** in lowercase, set in Readex Pro SemiBold (outlined in the SVG lockups, so no font is needed).

| Colour | Hex | Use |
|---|---|---|
| Navy | `#1B2F5B` | the mark, the wordmark, app icon background |
| White | `#FFFFFF` | the mark on navy or dark backgrounds |
| Gold | `#C9A227` | accent only (taglines, highlights), never the mark itself |

## Files

| File | Use |
|---|---|
| `renoxium-mark.svg`, `renoxium-mark.png` | The mark alone, navy, transparent background |
| `renoxium-mark-white.svg` | The mark for dark backgrounds |
| `renoxium-logo.svg`, `renoxium-logo.png` | Mark and wordmark side by side, navy, transparent |
| `renoxium-logo-white.svg`, `renoxium-logo-white.png` | The same for dark backgrounds |
| `renoxium-icon.svg`, `icon-192.png`, `icon-512.png` | App icon: white mark on a navy rounded square |
| `renoxium-avatar.svg`, `social-avatar.png` | Square navy avatar for social profiles (Instagram, X, LinkedIn, WhatsApp Business, Google Business); safe when cropped to a circle |
| `apple-touch-icon.png`, `icon-maskable-512.png` | Home-screen icons (iOS, Android); the platform rounds the corners |
| `favicon.ico`, `favicon.svg` | Browser tab icon; the SVG turns light in dark mode |
| `og-image.png` (1200×630) | Link preview when renoxium.com is shared on WhatsApp, X, LinkedIn, Facebook, Slack |
| `social-banner.png` (1500×500) | Header image for X and LinkedIn; the content is centred so the profile photo does not cover it |

The site serves these at `/favicon.ico`, `/favicon.svg`, `/apple-touch-icon.png`, `/icon-192.png`, `/icon-512.png`,
`/site.webmanifest`, `/og-image.png` and every file at `/brand/<file>`.

## Rules

- Keep clear space around the mark of at least the width of the R's stem.
- Do not recolour the mark other than navy or white, add effects, outline it, or rotate it.
- Below 24 px, use the mark alone, not the lockup.
