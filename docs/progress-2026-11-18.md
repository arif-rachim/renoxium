# Renoxium progress report, 18 November 2026

Renoxium is a Go platform where store owners build and run online shops by
chatting with ChatGPT or Claude. It runs at https://www.renoxium.com, with apps
on `*.renoxium.app`.

Work started on 15 November 2026. There are 57 commits on `main`, and the
version live in production is `a97d83f`.

## Where we are

The product is **feature-complete for a first launch in the UAE**:
- Payments run in Stripe **test** mode.
- Two things are still missing: approval from Meta for WhatsApp, and a legal
  review of the Privacy Policy and Terms.

## What is built

| Area | Status |
| --- | --- |
| Runtime | Done. One Go binary. Tenant scripts run in sandboxed worker processes with memory limits. Each app has its own SQLite database. Preview and live stages, publishing with the owner's confirmation, roll-back. |
| Builder agent | Done. OAuth 2.1 (dynamic registration, PKCE, refresh). MCP tools: `list_apps`, `create_app`, `get_app`, `apply_change`, `patch_app`, `test_request`, `upload_file`, `get_logs`, `publish`, `get_example`. |
| Store template (`store-uae`) | Done. Catalogue in English and Arabic, product options with their own price and stock, cart, discount codes, card payment and cash on delivery, AED with VAT, orders, printable tax invoices. |
| Shoppers | Done. Accounts by email and password or by WhatsApp code. Each shop has a public MCP for shoppers' AI assistants. |
| Card payments | Done. Stripe Connect (Accounts v2, the merchant's own Stripe account), Checkout as a direct charge, webhooks, refunds, sales summary. |
| Plans | Done. Free, Pro (AED 99) and Business (AED 299) through Stripe Billing: Checkout plus Customer Portal. Limits per plan: apps, staff, WhatsApp codes, image storage, custom domain. The Free plan has a 2% fee and the badge. |
| Admin panel | Done. Generated from the app schema: data tables, image uploads, visitors, staff, notifications by email and WhatsApp, payments, custom domain. |
| Custom domains | Done. Cloudflare for SaaS, with the fallback origin `customers.renoxium.app`. |
| Operator | Done. `/operator`: figures, search, giving a plan without payment, suspending apps, abuse reports, monitoring and alerts. |
| Account | Done. Change password, export data, delete the account (a paid plan is cancelled at once). |
| Security | Done. Hardened against takedown, account takeover and abuse: CSRF, rate limits, host checks, signed webhooks, apex `renoxium.com` never serves the site. |
| Operations | Done. Behind Cloudflare Tunnel. Auto-deploy on push to `main`. Daily local backup (cron 03:17). |

## Tests

- **Go:** 135 test functions (`go test ./...`), all passing.
- **End-to-end (`e2e/`, new on 18 November):** 35 scenarios, all passing twice
  in a row, in about 4 minutes.
  - The suite runs the real binary against fake Stripe, Resend, Meta and
    Cloudflare.
  - It covers every flow of owners, agents, shoppers, staff and the operator.
    See `e2e/README.md`.
- **Production demo (17 November):** a recorded run on www.renoxium.com in
  Stripe test mode. 13 of 13 steps passed. The test data was removed afterwards.

## Fixed this week from the demo's findings

- Sign-in now honours `next=` for `/account`, `/billing` and `/operator`.
- Deleting an account cancels its paid subscription at once. Before, deletion
  was refused until the period ended.
- Apps get a default favicon. Before, every first visit logged a 404 warning.
- The Payments page lists the documents Stripe asks for before onboarding.
  It also states the Free plan's 2% fee; it wrongly said "no fee" before.

## Configuration on the server

These are set in `/etc/renoxium/env`:
- Resend, for email
- WhatsApp: token, number ID, sign-in template
- Stripe test keys: Connect webhook, Pro and Business prices, billing webhook
- Cloudflare, for custom domains
- the operator address
- the legal name, address and email

## Known limits

- **Stripe onboarding in the UAE** asks for many documents and may show a
  CAPTCHA. The Payments page now prepares owners for it.
- **No traffic statistics** per app yet. The overview shows visitors, card sales
  and errors.
- **The E2E suite uses fakes.** Real Stripe, Meta and Cloudflare behaviour
  (CAPTCHA, currency, template approval) still needs a manual check in test or
  live mode.
